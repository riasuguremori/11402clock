🕰️ Eevee Nature Clock (伊布生態時鐘)
一個結合了實時時鐘與寶可夢生態模擬的互動式網頁專案。 在這個網頁中，你不僅能查看時間，還能觀察伊布在草原上的漫遊、追逐進化石，並根據日夜變化進化成不同的型態。

✨ 特色功能
1. 互動式時鐘
擬真指針：帶有微幅抖動 (Jitter) 動畫的時、分、秒針，模擬手繪或機械質感。

寶可夢球背景：整點或點擊時，中心的寶可夢球會開啟。

自動校時：與系統時間完全同步。

2. 生態模擬系統 (AI Logic)
自動生成：伊布會在草地上隨機生成並漫遊。

進化機制：

進化石掉落：系統會定時或經由手動操作投放 5 種進化石（火、水、雷、葉、冰）。

競速系統：當進化石落地，場上的伊布會計算距離並自動「追逐」石頭。先觸碰到的伊布會進化，失敗的伊布會停下。

進化特效：包含閃光與縮放的進化動畫。

3. 日夜交替系統
自動切換：根據當地時間（06:00 - 18:00 為白天）自動變換場景。

視覺特效：

白天：陽光普照的草原。

夜晚：視差滾動的星空背景、深藍色濾鏡。

型態連動：

切換至夜晚時，場上的「太陽伊布」會變身為「月亮伊布」。

切換至白天時，場上的「月亮伊布」會變身為「太陽伊布」。

4. 統計儀表板
左上角即時顯示目前場上各種進化型態的數量統計。

🎮 操作說明
切換日夜：點擊右上角的太陽/月亮按鈕，可強制切換日夜模式。

手動餵食：點擊中央的時鐘，會強制掉落一顆隨機進化石並生成一隻伊布，觸發進化爭奪戰
